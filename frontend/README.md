# CuccioloFinder Frontend

React SPA for browsing the dog adoption listings produced by the CuccioloFinder data pipeline. Served at `/cucciolofinder/` on [armanb.dev](https://armanb.dev).

## Stack

- Vite 7 + React 19
- React Router 7
- Bootstrap 5 + react-bootstrap
- Recharts + @nivo/heatmap for the stats dashboard
- @hcaptcha/react-hcaptcha for the contact form
